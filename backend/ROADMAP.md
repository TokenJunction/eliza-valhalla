# This slice

Done here:

- Customer API on the `docs/site` line, without replacing the marketing homepage.
- Admin email comes from `MASTER_ADMIN_EMAIL` or `CUSTOMER_ADMIN_EMAIL`. No address is hard-coded.
- Odin reports one provider at a time. Missing keys and a sleeping local machine stay unavailable.
- Trading Desk, Thalos, and Data Explorer are the paper or local apps. Other expert names are not configured.
- Connectors for Drive, GitHub, Cloudflare, and S3 or R2 stay not configured until a customer key and, for object storage, a prefix exist.
- Contributed compute is off. It does not mine and it does not pay a token.

Not in this slice: see `BACKLOG.md`.
